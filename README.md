# Salim Choudhary — Portfolio

A responsive single-page portfolio built with HTML and CSS.

## Preview locally
Open `index.html` in your browser.

## Customize
- Replace the `SC` initials block in the hero with your professional photo.
- Add verified GitHub repository/live-demo URLs to each project card.
- Add your resume PDF and update the Resume button/link when it is ready.

## Publish with GitHub Pages
1. Create a GitHub repository named `salim-portfolio` (or `<your-username>.github.io`).
2. Upload `index.html` (and this README).
3. In repository Settings → Pages, choose deploy from the `main` branch and `/ (root)`.
4. Save and wait for GitHub Pages to publish the site.
